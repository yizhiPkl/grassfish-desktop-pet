# 草鱼桌面小猫 🐾

<img src="./assets/portrait.png" alt="草鱼小猫" width="140">

**一只会陪你工作，也会提醒你好好吃饭、喝水的小猫。**

草鱼是一款 Windows 桌面宠物。平时可以在桌面陪着你；鼠标放到它身上，它会享受你的陪伴。你可以让它提醒喝水、吃饭，也可以添加自己的安排。

**不用安装 Codex，也能用草鱼的日程提醒。** 连接 Codex 只是可选功能。

> 当前发布：**0.1.9.4**。适用于 Windows x64；Codex 联动仍有版本兼容限制。

## 第一次用？从这里开始

你只需要下载一个安装文件，**不用编程，也不用下载整份源码**。

### 第一步：下载安装程序

👉 **[点击下载草鱼 0.1.9.4 安装程序](https://github.com/yizhiPkl/grassfish-desktop-pet/releases/download/v0.1.9.4/GrassFish-Setup-0.1.9.4-win-x64.exe)**（约 24 MB）

下载后的文件叫：**GrassFish-Setup-0.1.9.4-win-x64.exe**。

- 不要点绿色的 Code 按钮去下载源码，普通使用不需要它。
- 如果没有开始下载，打开[本版下载页](https://github.com/yizhiPkl/grassfish-desktop-pet/releases/tag/v0.1.9.4)，在 Assets（附件）里选择上面这个 .exe 文件。不要选 Source code，那是源码，不是安装程序。
- 如果下载打不开，先确认网络能访问 GitHub，再回到本页重新点击下载；不需要登录或申请仓库权限。
- **只从你信任的项目页面下载。** 当前安装程序还没有发布者数字签名，Windows 可能提示“未知发布者”；不要为了安装关闭杀毒软件。来源不明、文件名不符或校验不一致时，不要运行。

### 第二步：双击安装

1. 找到刚才下载的文件，双击打开。
2. 按页面提示点“下一步”。
3. 选择安装位置。不想改就用默认位置；也可以选择 D 盘中自己方便找到的文件夹。
4. 想在桌面放一个启动图标，就保留“创建桌面快捷方式”。
5. 如果看到“准备 Codex 任务界面”这个选项：
   - **只想用小猫和日程提醒：可以不勾选。**
   - **想连接 Codex：保留勾选。** 如果电脑缺少它需要的显示组件，安装器会联网从微软安装；已经有了就不会重复安装。
6. 安装完成，选择“启动草鱼桌面小猫”。

不需要填写账号、API 密钥或聊天会话编号。草鱼也不会擅自打开 Codex。

### 第三步：认识你的小猫

| 想做什么 | 怎么操作 |
| --- | --- |
| 打开控制面板 | **双击小猫** |
| 看快捷菜单 | **右键小猫**，点菜单外或按 Esc 可以收起 |
| 换个位置 | 拖动小猫 |
| 摸摸它 | 鼠标停在小猫身上 |
| 修改大小、互动和开机启动 | 打开控制面板，进入“草鱼设置” |
| 暂时不想看到小猫 | 右键菜单选择隐藏；可从右下角托盘图标再打开 |
| 退出程序 | 从小猫或托盘菜单正常退出 |

**关掉控制面板不等于退出小猫。** 小猫程序需要保持运行，才能准时提醒；电脑关机、睡眠期间不会弹出提醒。

## 怎么设置提醒？

### 喝水和吃饭

双击小猫打开控制面板，找到生活提醒，按需要设置时间或间隔，然后点“保存设置”。到时间时，草鱼会说：

- **该喝水了喵**
- **该吃饭了喵**

### 加上你自己的安排

在控制面板找到日程设置，填写标题、时间和提醒内容，再保存这个约定。

例如：每天晚上提醒休息、每隔一小时起来活动、每周固定开会，或者明天下午取快递。支持**一次、每天、每周、按间隔**提醒。

### 提醒弹出来以后

> 以下交互已包含在 0.1.9.4 中。

- **完成**：这一次已经做完了。
- **稍后提醒**：过几分钟再叫你，可以选择时间。
- **跳过**：跳过这一次，不会关掉以后所有提醒。不再额外显示 × 收起按钮。

新建或编辑日程时可勾选“重要约定”，已有待处理事项也能在“**今日小事**”里调整重要性。重要提醒优先显示，免打扰时仍会提醒；多个重要事项按到期时间依次显示，不叠开多个窗口。主动选择稍后提醒时，仍会等到你指定的时间。

打开“**今日小事**”，可以查看今天的安排、待处理事项和稍后提醒。旧版“已收起”记录保留，并统一显示在“已跳过”中，不冒充完成。普通到期日程也不会被 Codex 完成提示一直挡住；日程处理后，未确认的任务完成提示继续显示。任务完成提示正文简化为“喵喵喵”，点“知道啦”收好。

已处理记录按 7 天定期清理，最多保留 200 条。**没处理和稍后的事项，不会因为过了七天就自动消失。**

### 想安静一会儿？

可以选择安静 30 分钟、1 小时，或者设置每天的安静时段。提醒会先等着，不会直接删除；你也可以随时恢复。

## 想让草鱼显示 Codex 的任务？这是可选项

不需要这个功能，可以跳过这一节。

1. 先在自己的电脑上打开 **Codex 桌面软件**。
2. 在 Codex 里已经有一个本机对话；完全空白时，请先自行创建一个。
3. 打开草鱼控制面板 →“草鱼设置”。
4. 勾选“**连接本机 Codex，显示任务数量**”。
5. 等待几秒，小猫下方会出现任务入口。点数字可以展开；点任务标题可以打开原来的 Codex 对话，回复框可以继续跟进。

草鱼会寻找**你自己电脑上的对话**，不需要作者的配置。回复只有在你明确发送时才会交给 Codex。停止任务、处理审批和查看完整工具内容，请回到 Codex 原窗口操作。

**这项功能还在测试，不能保证所有 Codex 版本都能连接。** 当前确认适配的是 Windows Codex **26.1007.9446.0 和 26.1013.3656.0**。草鱼会自动寻找当前用户可用的任务入口，并可继续使用本机已经完整校验的旧版界面缓存；这不等于保证任意未来版本都兼容。连接不上不影响吃饭、喝水和自定义日程提醒。目前还没有第二台实体电脑的完整验收。

## 常见问题

### 我的电脑能装吗？

当前安装程序面向 **Windows 10 / Windows 11 的 64 位电脑**。Windows 10 需要 2004 或更新版本。不支持 macOS、Linux 或 32 位 Windows。

如果安装器提示缺少 .NET Framework 4.8，这是 Windows 的运行组件，不是让你安装编程软件。先通过 Windows 更新或微软官方安装程序补齐，再重新安装草鱼。

### 下载了 ZIP，不是安装文件，怎么办？

新手建议下载上面的 .exe 安装程序。

如果你想用便携版，可以下载 [0.1.9.4 便携 ZIP](https://github.com/yizhiPkl/grassfish-desktop-pet/releases/download/v0.1.9.4/GrassFish-0.1.9.4-win-x64-portable.zip)，**先全部解压到一个固定文件夹**，再运行里面的 DesktopKitten.exe。不要只把一个 exe 拖出来，也不要直接在压缩包里运行。

### 小猫不见了怎么办？

先看右下角的托盘区域，必要时点向上的小箭头，找到小猫图标，再选择显示小猫或打开控制面板。

### 为什么没提醒我？

检查：小猫程序是不是还在运行、提醒有没有启用和保存、时间是否正确、是否开启了免打扰或点过“稍后提醒”。

### Codex 连接不上怎么办？

先确认 Codex 正在运行、有本机对话，并且草鱼中已勾选联动。如果仍然失败，请记录两边的版本和错误提示反馈。**不用重装所有东西，也不要删除 Codex 的账号或配置。**

### 怎么更新？会丢日程吗？

**0.1.9.0 起**，打开“小窝 → 关于草鱼”，可以看到真实版本和“检查更新”。默认最多每天检查一次，也可以关闭自动检查。发现新版时会告诉你改了什么，由你选择更新、稍后或跳过，**不会偷偷下载安装**。

选择更新后会先下载、检查文件，再安装重启草鱼，保留日程和设置。有回复草稿、正在发送的消息或小窝未保存编辑时不会强退，也不会关闭 Codex。安装失败会尝试恢复旧文件；这不是所有系统故障下都能保证成功的完整回滚，若提示恢复失败，请保留备份并手动重装。

**0.1.8.x 及更早版本需要先手动安装一次新版**，以后才有内置更新。手动升级时，先处理回复草稿，从小猫菜单正常退出，再运行新版安装程序，安装到原来的位置。正常升级保留个人设置和日程，不需要先卸载旧版。

### 怎么卸载？

先正常退出小猫，再到 Windows“设置 → 应用”中找到草鱼桌面小猫，选择卸载。默认保留个人日程和设置，方便以后装回来。

### 想核对下载文件有没有变化？

下载本版的 [SHA256SUMS.txt](https://github.com/yizhiPkl/grassfish-desktop-pet/releases/download/v0.1.9.4/SHA256SUMS.txt)。[文件校验说明](./docs/文件校验.md)里有一步一步的操作。校验能确认文件一致，**不等于已经获得 Windows 发布者认证**。

## 0.1.9.4 改了什么？

- 鼠标跟随转头升级为全新 32 方向，修正左下角多余耳廓，方向切换更细腻；原待机及其他动作不变。
- 统一日程与任务提示优先级，支持新建、编辑日程及在“今日小事”中设置重要事项，到点优先显示。
- 提醒弹窗仅保留“完成、稍后提醒、跳过”，取消额外的 × 收起按钮，简化“今日小事”。
- 任务完成提示正文简化为“喵喵喵”，点击“知道啦”后按原动画回到待机。
- 已装 0.1.9.0 或更新版本可通过“小窝 → 关于草鱼 → 检查更新”升级，保留日程与设置，无需先卸载。Codex 兼容范围未扩大。
