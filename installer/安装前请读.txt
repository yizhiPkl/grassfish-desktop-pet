草鱼桌面小猫 · 0.1.8.1

独立日程提醒桌宠，支持喝水、吃饭、自定义日程、稍后提醒、今日小事和手动免打扰。不安装 Codex 也能使用这些功能。

系统：Windows 10 2004（19041）及以上的 Windows 10/11，64 位，Microsoft .NET Framework 4.8。
安装在当前用户目录，不要求管理员权限。可以自行选择 D 盘等可写位置。不会自动开启开机启动，卸载保留个人设置。

Codex 联动是可选的实验兼容功能：
1. 需要当前用户已经启动 Windows Codex 桌面端，并已有一个本地 Codex 对话。
2. 自动从当前用户的 CODEX_HOME 或 .codex 目录发现本地会话，不需要作者的配置、账号、会话 ID 或 API 密钥。
3. 已验证兼容的原生任务组件来自 Codex 26.1007.9446.0。此安装包不包含 Codex 的原生界面文件；仅在需要展开任务界面时，从用户自己运行中的 Codex 安装目录读取并校验资源。不会改写 Codex 安装包。
4. 任务列表、打开原对话、回复功能依赖 Codex 的内部桌面接口，不是官方稳定公共 SDK。Codex 更新、企业策略、不同安装形式或权限可能导致不可用。草鱼会显示错误，日程功能仍可用，不会自动建立任务或另起后端。
5. 展开的任务界面需要 Microsoft Edge WebView2 Runtime。缺少时，选中的可选组件会联网从 Microsoft 安装运行时；已有运行时则直接共用。只需要独立日程功能时可以取消。
6. 回复只会在你明确点击发送时发送到所选本地对话。失败保留草稿；超时结果不明时不自动重发。停止任务请在 Codex 原对话中操作。

隐私：设置、日程和本地兼容缓存保存在当前用户 LocalAppData/DesktopKitten。草鱼不读取 Codex 认证文件，不上传自己的遥测，不打包作者个人日程或对话。Codex 本身的网络通信由你自己的 Codex 控制。

本安装包尚无发布者代码签名，系统可能提示未知发布者。请从项目可信发布页下载并核对 SHA-256。不要把此实验联动标注成“所有 Codex 版本通用”。
