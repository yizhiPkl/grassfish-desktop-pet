# 开发说明（普通使用者不用看）

## 源码内容

- src：C# / WPF 程序、调度逻辑和隔离测试。
- assets：猫咪素材及草鱼自己的小型任务宿主页；不含 Codex 官方 vendor 文件。
- lib/webview2：Microsoft WebView2 SDK 的必要 DLL，随附许可和 NOTICE。
- installer：Inno Setup 安装脚本和中文界面文件。
- tools：构建、打包和上传前检查。
- downloads：已检查的 0.1.8.1 安装程序、便携包和校验单。普通用户从 README 下载即可。

本仓库从当前干净快照开始记录，不继承旧开发历史。上传前检查不能只看忽略规则，还要检查实际提交和历史对象。

## 编译

在 Windows x64 上准备 .NET Framework 4.8 和 Windows 自带的 Framework 编译工具。源码使用脚本编译，不需要 Python、Node 或 FFmpeg 才能运行程序。

在工程根目录的 PowerShell 中执行：

~~~powershell
./tools/build.ps1 -Public
~~~

输出位于 release/桌面小猫。保留 exe 旁边的 assets、运行配置和三个 WebView2 DLL。

运行隔离自检：

~~~powershell
./release/桌面小猫/DesktopKitten.exe --self-test ./release/self-test.json
~~~

程序是窗口应用，从脚本运行测试时应等待退出后读取结果。不要用真实 Codex 会话测试发送或停止操作。构建与测试输出不提交。

## 制作安装程序

额外准备 Inno Setup 6，以及从微软官网下载的 MicrosoftEdgeWebview2Setup.exe。构建脚本会检查后者的微软数字签名。不要提交证书、账号、运行环境安装器或本机工具目录。

~~~powershell
./tools/build-installer.ps1 -InnoCompiler '你的编译器目录/ISCC.exe' -WebView2Bootstrapper '你的下载目录/MicrosoftEdgeWebview2Setup.exe'
~~~

需要重新构建同一版本时，使用新的 ReleaseDirectory，避免混入旧文件。默认输出在 release 下，被 Git 忽略。

## Codex 适配边界

当前原生组件针对 Windows Codex MSIX 26.1007.9446.0 做了适配。接口属于版本兼容路径，不是稳定的外部桌面 SDK；其他版本、安装形式或权限限制可能导致不可用。

连接只在桌面 Codex 已运行时尝试。调用前验证工具能力与管道服务进程，并从当前用户 CODEX_HOME 或 .codex 发现已有本地会话。不读取认证文件、不写 SQLite 或 rollout、不新建任务、不另起后端。

任务界面展开时，从用户运行中的 Codex 只读提取匹配哈希的组件；缓存只在用户本地。不把提取结果提交或打包。失败时保留独立日程功能，并明确显示错误。收起后的 15 秒温缓存策略保持不变。

真实会话的自动发现、列表和读取已在开发电脑验证；发送目标和失败草稿使用隔离管道测试。原版组件挂载及回复框使用不可见的嵌入式界面测试。没有第二台实体电脑端到端验收，也没有为了测试而发送真实聊天消息，不能将这些检查宣传为全部用户或所有 Codex 版本已通过。

0.1.8.1 先前安装版本记录：8,771 项自检、32 项离屏 WPF 检查和 5 项原版组件检查通过；安装、升级、卸载已跑通。这是已有版本验证记录，不冒充每次改动都已重新执行。
