# 怎么核对下载文件？（可选）

如果你担心下载的文件不完整或被替换，可以核对它的“文件指纹”，也就是 SHA-256。

1. 在本版 GitHub Release 下载页，把安装程序和同一版的 SHA256SUMS.txt 下载到同一个文件夹。0.1.9.5 的下载入口见首页；仓库 downloads 文件夹里的校验单仅对应 0.1.8.1 历史包，不要混用。
2. 在该文件夹的空白处按住 Shift 点右键，选择在终端或 PowerShell 中打开。
3. 输入下面这一行，按回车：

~~~powershell
Get-FileHash .\GrassFish-Setup-0.1.9.5-win-x64.exe -Algorithm SHA256
~~~

4. 用记事本打开 SHA256SUMS.txt，找到安装程序那一行。
5. 两边那一长串字母和数字应完全相同；大小写不影响比较。

不相同就不要运行，先重新从可信的项目页面下载。指纹一致能说明文件与发布清单相同，**不能代替发布者数字签名，也不能独自证明软件安全**。
