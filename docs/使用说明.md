# 使用说明

0.1.9.4的随鼠标转头使用用户提供视频提取的32个方向，全部为新视频完整帧，不混入旧转头图。原待机、眨眼、摸摸、工作和任务完成动画保持不变。鼠标在中心附近或超出跟随范围时仍返回原待机；快速跨方向时按最短角度路径追随，不强制播放整圈。本版同时包含此前0.1.9.3的提醒与交互改进。

普通使用请先看工程首页 README.md，里面有从下载到安装、设置提醒、连接 Codex和卸载的完整新手教程。

当前0.1.9.4的提醒纸条只保留“完成”“稍后提醒”“跳过”，没有额外的 × 收起按钮。“完成”只处理当前一次；“稍后提醒”可以选择5、10、30分钟或自定义；“跳过”不关闭后续重复安排。今日小事沿用同样的三个操作，旧版“已收起”记录保留在“已跳过”中，不记为完成。

新建或编辑约定可勾选“重要约定”，今日小事也可调整已有事项的重要性。开启“日程提醒提示”时，重要提醒优先于普通日程和 Codex 完成提示，免打扰时仍会出现；多个重要提醒按到期时间依次展示，不叠加弹窗。主动延期的事项仍按稍后时间提醒。修改自定义约定的重要性同步影响当前未处理事项和后续提醒，不改变原来的时间、重复规则或稍后时间。

普通到期日程也不必等待 Codex 完成提示被确认；日程处理后，尚未确认的任务提示会继续显示。任务完成提示只说“喵喵喵”，点击“知道啦”后仍按原动画自然回到待机。以上功能均包含在0.1.9.4中；旧版用户可通过内置检查更新或安装程序升级，保留个人设置与日程。

已处理记录按7天定期清理、最多200条；未处理和稍后事项保留到用户处理。提醒依赖小猫程序运行。

## 提示窗口（0.1.9.5起）

0.1.9.5新增：小窝 → 草鱼设置 → 提示窗口提供三个独立开关，点击立即生效并保存在本机，旧设置升级时默认全部开启：

- **任务完成提示**：控制“喵喵喵 / 知道啦”的完成纸条。关闭只隐藏纸条，任务完成后草鱼仍持续摇尾巴，没有5秒自动收起。鼠标新移到猫的非透明区域并停留0.3秒后，按原有复位动画回到待机；未满0.3秒移开则继续摇尾巴，下次移入重新计时。实际拖动超过原有阈值后也会结束这次提醒，沿用行走与松手待机，不必等这0.3秒。原本已停在猫身上的鼠标、单击和轻微抖动不会自动确认。开启纸条时沿用“知道啦”确认方式。
- **任务通知浮窗**：控制草鱼下方的任务数字与自动浮窗。不影响 Codex 连接、工作或完成动画；从小窝或托盘点“任务通知”仍可手动打开，并保持到主动收起。关闭不清除任务或未发送的回复草稿。
- **日程提醒提示**：控制喝水、吃饭、自定义约定和免打扰结束汇总，重要约定也遵守此开关。关闭仅隐藏窗口，未处理、稍后和历史事项仍在“今日小事”，不会自动完成或跳过。重新开启时按原有重要性与到期顺序展示一个提醒窗口。

这些开关不关闭任务监测或日程本身，也不覆盖其他尚未保存的设置编辑。关闭“小纸条”不等于安静时段：前者明确禁止弹窗，后者仍允许重要约定提醒。关闭完成纸条后，对摇尾巴的确认仅属于草鱼本地提示，不会把真实 Codex 对话标记已读。

Codex 是可选联动：先启动自己的 Codex，并已有本地对话，再勾选草鱼设置中的连接选项。0.1.8.2 支持 Windows Codex 26.1007.9446.0 和 26.1013.3656.0，会自动寻找可用的任务入口，并优先沿用本机已经验证可用的任务界面缓存，不需要复制别人的账号或对话配置。未来版本若改变内部接口，或新电脑没有可用的界面缓存，仍可能需要更新草鱼；独立日程不受影响。项目首页 downloads 中的 0.1.8.1 旧安装包不包含此次改进。

安装、升级、卸载及未知发布者提示的说明均见 README。不要为安装关闭安全软件，也不要发送账号、认证文件、证书私钥或个人日程给项目维护者。

## 草鱼怎么更新（0.1.9.0 起）

打开小窝 → 关于草鱼，可以看到本机真实版本和“检查更新”。默认在启动约30秒后检查，最多每天一次；不想自动检查，可以关闭开关，仍能手动检查。

有新版本时会出现小窗口，告诉你改了什么。你可以点“立即更新”、稍后再说，或跳过这个版本。只有点击更新才会下载，下载完会核对文件，再重启草鱼完成安装；不会顺手关闭 Codex。

回复框还有没发送的文字、消息正在发送，或者小窝有没保存的编辑时，草鱼不会强制退出。请先处理这些内容，再点安装。更新保留提醒和设置。网络或下载出问题时旧版仍然可以用；安装失败会尝试恢复旧文件，如果提示未恢复完成，请手动重装，不要删除备份。

旧版需要先手动安装一次带此功能的新版。维护者还没把新版本正式放到 GitHub Release 时，检查不到更新是正常的。Windows 的“未知发布者”提示与此更新校验不是一回事，目前仍没有发布者数字签名。
