# 使用说明

普通使用请先看工程首页 README.md，里面有从下载到安装、设置提醒、连接 Codex和卸载的完整新手教程。

提醒纸条的“完成”只处理当前一次；“稍后提醒”可以延期；“这次跳过”不关闭后续重复安排；×只收起、不计完成。今日小事可以找回收起的事项。

已处理记录按7天定期清理、最多200条；未处理和稍后事项保留到用户处理。提醒依赖小猫程序运行。

Codex 是可选联动：先启动自己的 Codex，并已有本地对话，再勾选草鱼设置中的连接选项。当前适配 Windows Codex 26.1007.9446.0，其他版本可能不可用；独立日程不受影响。

安装、升级、卸载及未知发布者提示的说明均见 README。不要为安装关闭安全软件，也不要发送账号、认证文件、证书私钥或个人日程给项目维护者。
