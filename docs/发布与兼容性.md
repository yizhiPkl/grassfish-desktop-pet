# 发布与兼容性

当前源码版本为 0.1.9.0。downloads 中的 0.1.8.1 安装程序和便携包尚未替换；不要把源码改进描述为旧发行包已经具备的功能。

- Windows 10 2004（19041）及以上的 Windows 10/11 x64；需要 .NET Framework 4.8。缺少时安装器给出提示。
- 当前用户安装，默认 LocalAppData/Programs/GrassFish，可选择其他可写目录；不自动设置开机启动。
- 安装器包含可选的微软 WebView2 联网引导安装程序；便携 ZIP 不含运行时安装器。独立日程不依赖该任务显示组件。
- 升级前正常退出并保存回复草稿；不强制结束进程。卸载保留当前用户 LocalAppData/DesktopKitten 的设置和日程。
- 无发布者代码签名；请从可信页面下载并核对 SHA-256，校验不能代替身份认证。
- 0.1.9.0 增加可关闭的每日更新检查与手动检查。只从固定项目的 GitHub 正式 Release 读取更新；只有用户点击才下载安装。更新说明必须通过内置公钥验证，安装包再核对大小和 SHA-256。该机制不是 Windows 发布者代码签名，不会消除未知发布者或 SmartScreen 提示。
- 内置更新沿用现有可写安装位置；存在回复草稿、正在发送的消息或小窝未保存编辑时不退出。先备份应用自有文件，失败时尝试恢复；这不是所有系统故障下的完整事务回滚。日程、设置和 Codex 缓存不在安装器覆盖范围。安装期临时启动助手，结束后退出；没有常驻更新进程。
- 旧版没有内置更新，需要先手动安装一次新版。自动更新服务真正可用还需要维护者获准后发布带签名的完整 GitHub Release；不能将本地打包或隔离测试当成线上端到端更新验收。
- Codex 可选联动仅在现有桌面程序运行时连接。当前源码的原生组件适配 Windows Codex MSIX 26.1007.9446.0 和 26.1013.3656.0；不承诺未来版本、非标准安装或所有电脑通用。连接自动探测已知入口族的任务能力，界面可沿用本机完整校验过的旧缓存。
- 公开内容不含官方任务 vendor JS/CSS 或作者个人会话配对。无可用缓存时，组件从当前用户运行中的 Codex 只读提取并逐文件校验；只识别发行源码内的可信适配清单，提取结果不上传。未知新版本且没有有效缓存时，提示更新草鱼，不盲目加载未知组件或联网下载可执行适配脚本。
- 不自动新建对话，不改模型或认证，不另起 app-server；回复由用户主动发送，超时不自动重发，失败保留草稿。停止任务请在 Codex 原对话操作。
- 该仓库为干净初始快照，不继承原开发仓库历史。downloads 中的安装文件保持既有检查版本原字节，未因重写 README 而偷偷替换。
- 尚无第二台实体电脑的端到端验收；独立日程与 Codex 兼容范围请分开说明。草鱼不是 OpenAI 官方产品。
