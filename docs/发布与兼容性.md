# 0.1.8.1 发布与兼容性

- Windows 10 2004（19041）及以上的 Windows 10/11 x64；需要 .NET Framework 4.8。缺少时安装器给出提示。
- 当前用户安装，默认 LocalAppData/Programs/GrassFish，可选择其他可写目录；不自动设置开机启动。
- 安装器包含可选的微软 WebView2 联网引导安装程序；便携 ZIP 不含运行时安装器。独立日程不依赖该任务显示组件。
- 升级前正常退出并保存回复草稿；不强制结束进程。卸载保留当前用户 LocalAppData/DesktopKitten 的设置和日程。
- 无发布者代码签名；请从可信页面下载并核对 SHA-256，校验不能代替身份认证。
- Codex 可选联动仅在现有桌面程序运行时连接。当前原生组件适配 Windows Codex MSIX 26.1007.9446.0；不承诺未来版本、非标准安装或所有电脑通用。
- 公开内容不含官方任务 vendor JS/CSS 或作者个人会话配对。组件从当前用户运行中的 Codex 只读提取并逐文件校验，提取结果不上传。
- 不自动新建对话，不改模型或认证，不另起 app-server；回复由用户主动发送，超时不自动重发，失败保留草稿。停止任务请在 Codex 原对话操作。
- 该仓库为干净初始快照，不继承原开发仓库历史。downloads 中的安装文件保持既有检查版本原字节，未因重写 README 而偷偷替换。
- 尚无第二台实体电脑的端到端验收；独立日程与 Codex 兼容范围请分开说明。草鱼不是 OpenAI 官方产品。
